# Chibi Office 3D (Three.js)

Teste mínimo: cena Three.js + Vite publicada no GitHub Pages via GitHub Actions.

**Site:** https://matheusgsd.github.io/office/

## Rodar local

```sh
npm install
npm run dev
```

## Publicar no GitHub Pages

1. Em **Settings → Pages**, escolha **Source: GitHub Actions**.
2. Faça push (ou rode o workflow "Deploy no GitHub Pages" manualmente em **Actions**).
3. O site fica em `https://<usuario>.github.io/<repo>/`.
